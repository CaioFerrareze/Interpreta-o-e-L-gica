# 🧠 Desafios de Lógica e Interpretação com JavaScript

Este repositório contém quatro desafios simples de lógica e interpretação, resolvidos utilizando **JavaScript**. O objetivo é aprimorar o raciocínio lógico e a capacidade de resolver problemas de forma eficiente.

## 🚀 Tecnologias Utilizadas
- JavaScript (ES6+)

## 📌 Desafios
Cada desafio está estruturado em um arquivo separado dentro da pasta `/desafios`.  
Os desafios abordam diferentes aspectos da lógica de programação, como manipulação de strings e números e estruturas condicionais.
